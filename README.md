# ptycho-packages
A selected list of **publicly available ptychography packages**.

This repo-approach is inspired by T. Aarholt's repo for [STEM simulation software](https://github.com/thomasaarholt/STEMSimulation).
Feel free to contact me or make PR to update this table.

Author: Chia-Hao Lee (cl2696@cornell.edu)

---
| **Year** | **Reference**                                                                                                                                           | **Supported Algorithms**       | **Language**          | **Notes**                                                                                                     |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------| --------------------- | --------------------------------------------------------------------------------------------------------------|
| 2025     | [PtyRAD](https://github.com/chiahao3/ptyrad) (Lee 2025)                                                                                                 | AD                             | Python                | PyTorch-based AD package for electron and x-ray ptychography.                                                 |
| 2025     | [phaser](https://github.com/hexane360/phaser) (Gilgenbach 2025)                                                                                         | ePIE, LSQML, AD                | Python                | Jax-based package with AD and conventional algos with different backends like cupy and pytorch (experimental) |
| 2025     | [pty-chi](https://github.com/AdvancedPhotonSource/pty-chi) (Du 2025)                                                                                    | ePIE family, DM, LSQML, AD, BH | Python                | PyTorch-based ptychography engine (use Ptychodus for preprocessing)                                           |
| 2025     | [ptyrodactyl](https://github.com/debangshu-mukherjee/ptyrodactyl)                                                                                       | AD                             | Python                | Jax-based AD for electron and optical ptychography                                                            |

| 2024     | [torchslice](https://static-content.springer.com/esm/art%3A10.1038%2Fs41467-023-44268-x/MediaObjects/41467_2023_44268_MOESM4_ESM.zip) (Diederichs 2024) | AD                             | Python                | Optimize discrete atomic models with thermal diffuse scattering.                                              |
| 2023     | [Deep-CDI](https://github.com/dillanchang/deep-phase-imaging) (Chang 2023)                                                                              | Pretrained NN                  | Python                | CNN prediction for coherent diffractive imaging (CDI).                                                        |
| 2023     | [PtyLab](https://github.com/PtyLab) (Loetgering 2023)                                                                                                   | ePIE family                    | MATLAB, Python, Julia | Fourier & conventional ptychography; mPIE, zPIE, aPIE, pcPIE, e3PIE.                                          |
| 2022     | [Tike](https://github.com/tomography/tike) (Gürsoy 2022)                                                                                                | ePIE, LSQML                    | Python                | Laminography, tomography from ptychographic reconstructions.                                                  |
| 2022     | [SciComPty](https://zenodo.org/records/6524326) (Guzzi 2022)                                                                                            | AD                             | Python                | A modular framework for the design of new ptychography algorithms with simulations.                           |
| 2022     | [Airpi](https://github.com/ThFriedrich/airpi) (Friedrich 2022)                                                                                          | Pretrained NN                  | Python                | CNN recovering complex specimen transmission functions from CBEDs.                                            |
| 2021     | [fold_slice](https://github.com/yijiang1/fold_slice) (Chen 2021)                                                                                        | ePIE, DM, LSQML                | MATLAB                | Modified PtychoShelves for electron ptychography.                                                             |
| 2021     | [PtychoNN](https://github.com/mcherukara/PtychoNN) (Cherukara 2020)                                                                                     | Pretrained NN                  | Python                | Predicts amplitude/phase directly from diffraction data alone.                                               |
| 2021     | [Ptychopy](https://github.com/kyuepublic/ptychopy) (Yue 2021)                                                                                           | ePIE, DM, LSQML                | Python                | CUDA C++ backend.                                                                                             |
| 2021     | [py4DSTEM](https://github.com/py4dstem/py4DSTEM) (Savitzky 2021, Varvanides 2023)                                                                       | SSB, WDD, DM, RAAR, GD         | Python                | Full 4D-STEM toolbox beyond ptychography.                                                                     |
| 2021     | [Ptychography 4.0](https://ptychography-4-0.github.io/ptychography/install.html#) (Weber et al.)                                                        | SSB                            | Python                | Supports live processing (SSB).                                                                               |
| 2021     | [Adorym](https://github.com/mdw771/adorym) (Du 2021)                                                                                                    | AD                             | Python                | HPC AD framework for 2D/3D ptychography, CDI, holography, tomography.                                         |
| 2021     | [PtychoKeras](https://opticapublishing.figshare.com/articles/software/Supplemental_Code_1_zip/13008155) (Seifert 2021)                                  | AD                             | Python                | TensorFlow/Keras AD implementation.                                                                           |
| 2020     | [PtychoShelves](https://www.psi.ch/en/sls/csaxs/software) (Wakonig 2020)                                                                                | ePIE, DM, LSQML                | MATLAB                | MATLAB-based GPU-accelerated engines for mixed state multislice. X-ray focused.                               |
| 2020     | [PyNX](https://gitlab.esrf.fr/favre/PyNX) (Favre-Nicolin 2020)                                                                                          | ER, RAAR, DM, ML               | Python                | CDI, ptychography, wavefront propagation, scattering calculations.                                            |
| 2020     | [abTEM](https://github.com/abTEM/abTEM) (Madsen 2021)                                                                                                   | PIE                            | Python                | Flexible package for simulating S/TEM experiments.                                                            |
| 2019     | [ptychoSampling](https://github.com/saugatkandel/ptychoSampling?tab=readme-ov-file) (Kandel 2019)                                                       | AD                             | Python                | Generalized forward models: near-field ptychography, 3D Bragg projection ptychography.                        |
| 2018     | [NSLS-II (Ptycho_gui)](https://github.com/NSLS-II/ptycho_gui) (Dong 2018)                                                                               | DM                             | Python                | Deployed on NSLS-II beamline machines with GUI.                                                               |
| 2016     | [PtyPy](https://ptycho.github.io/ptypy/) (Enders 2016)                                                                                                  | DM, RAAR, ePIE, ML             | Python                | Supports on-the-fly reconstructions; mixed probe and object.                                                  |
| 2015     | [(py)ptychoSTEM](https://gitlab.com/ptychoSTEM/ptychoSTEM) (Pennycook 2015; Yang 2015, 2016)                                                            | SSB, WDD                       | MATLAB, Python        | Direct ptychographic phase reconstructions with 4D STEM data.                                                 |
